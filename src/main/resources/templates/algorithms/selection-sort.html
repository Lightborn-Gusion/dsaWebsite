What is Selection Sort?

Selection Sort is an in-place comparison sorting algorithm. It divides the input list into two parts: a sorted sublist built up from left to right, and a sublist of the remaining unsorted items.

Key Concept: The algorithm repeatedly scans the unsorted part to find the absolute minimum (smallest) element, and then swaps it into the correct position at the end of the sorted portion. Like Bubble Sort, it also has a time complexity of O(n²), making it inefficient for large lists, but very easy to understand.
