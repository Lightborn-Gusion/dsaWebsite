What is Bubble Sort?

Bubble Sort is a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order.

Key Concept: The pass through the list is repeated until the list is sorted. The algorithm gets its name because smaller elements "bubble" to the top of the list, while larger elements sink to the bottom. It has a time complexity of O(n²).
