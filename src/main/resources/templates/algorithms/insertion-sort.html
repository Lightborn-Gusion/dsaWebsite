What is Insertion Sort?

Insertion Sort is a simple sorting algorithm that builds the final sorted array one item at a time. It is much like sorting playing cards in your hands.

Key Concept: The algorithm takes one element at a time (the "key") and compares it to the elements before it. If the previous elements are larger, it shifts them to the right to make room, and then inserts the key into its correct spot. While it also has a time complexity of O(n²), it is highly efficient for small data sets or lists that are already mostly sorted.
