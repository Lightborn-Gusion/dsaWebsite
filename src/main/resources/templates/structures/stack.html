What is a Stack?

A Stack is a linear data structure that follows the LIFO (Last-In, First-Out) principle. This means the last element added to the stack is the first one to be removed.

Key Concept: Think of a stack of plates; you add a plate to the top (Push) and take the top plate off (Pop). It is commonly used for reversing data and managing function calls in recursion.
