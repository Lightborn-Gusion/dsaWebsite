What is a Hash Table?

A Hash Table (or Hash Map) is a data structure used to store information in key-value pairs. It uses a mathematical algorithm called a Hash Function to take a key (like a username) and scramble it into a specific index number.

Key Concept: Because the hash function tells the computer exactly which memory "bucket" to look in, Hash Tables don't need to search through the data. This gives them lightning-fast, near-instantaneous speeds of O(1) for looking up, inserting, or deleting data. They are heavily used in databases and caching systems.
