What is a Doubly Linked List?

A Doubly Linked List is a variation of the linked list where each node contains three parts: the data, a pointer to the next node, and a pointer to the previous node.

Key Concept: Because each node points both forward and backward, traversal can happen in both directions (bidirectional). This makes operations like deleting a specific node or iterating backwards much more efficient, though it requires slightly more memory to store the previous pointer.
