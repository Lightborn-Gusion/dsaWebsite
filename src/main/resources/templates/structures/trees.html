What is a Tree?

A Tree is a non-linear, hierarchical data structure that consists of nodes connected by edges. Unlike arrays or lists, which are linear, trees represent data in a parent-child relationship.

Key Concept: Every tree has a single 'Root' node at the top, and nodes at the very bottom with no children are called 'Leaves'. This structure is essential for efficient searching and sorting algorithms like Binary Search Trees.
