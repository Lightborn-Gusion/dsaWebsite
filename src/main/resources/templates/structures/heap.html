What is a Heap?

A Heap is a special kind of complete binary tree that satisfies the "Heap Property." In a Max-Heap, the parent node is always strictly greater than or equal to its child nodes. In a Min-Heap, the parent is always smaller.

Key Concept: Because of this strict ordering, the largest (or smallest) element is always instantly accessible at the very top (the root). This makes heaps the absolute best data structure for building Priority Queues and powers the highly efficient Heap Sort algorithm.
